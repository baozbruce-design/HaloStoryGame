# 夢境水晶戰記：逆行鐘塔

以哈羅、波波、泡泡與「永冬鐘塔／十二點零一分」故事線改編的離線瀏覽器戰棋遊戲原型。玩法方向參考 FFT／皇家騎士團類型，但角色、故事與系統為此專案自己的版本。

## 啟動
直接雙擊 `index.html`，建議使用 Chrome 或 Edge。首次點「開始新戰鬥」後，瀏覽器才會允許播放音樂與音效。

## 戰棋系統
- 22 × 18 等角戰棋大地圖，1～5 層高度
- Move / Jump / Range，高低差會限制移動並影響射程與傷害
- 鏡冰地形會增加移動成本
- 正面／側面／背面判定：側擊與背擊提高命中、爆擊，背擊另有傷害加成
- 面向系統：待機時可選最後朝向
- 反擊／反應判定：目標存活且射程允許時可能反擊，背後遭襲時反擊率較低
- 戰鬥預測：瞄準敵人時顯示預估傷害、命中率、爆擊率、高地／背擊／反擊提示
- 移動為「暫定」：只要尚未攻擊、技能、道具或待機，就可按「撤回移動」，也可按 Z / Esc 回到移動前位置
- 路徑移動動畫、弓箭／魔法投射物、命中特效、鏡頭震動、傷害浮字、爆擊特效
- 行動完成會自動切換到下一名尚未行動角色，仍可手動改點其他可行動角色
- 範圍視覺化：藍色移動區、紅色移動後攻擊外圈、可開關的紫紅色敵軍聯合威脅區
- 我方／敵方回合、速度順序預覽、敵方 AI 自動尋路與攻擊
- 小地圖可點擊快速移動；WASD／方向鍵移鏡頭；右鍵／中鍵拖曳地圖
- SRW 風格大指令視窗：技能／道具點擊後中央彈出，左側顯示角色立繪、HP／MP、等級與狀態，右側以大字卡片顯示消耗、射程、範圍與效果
- 角色能力頁改為大尺寸狀態視窗，顯示面向、行動狀態、Buff／Debuff、Range 與完整能力；右側角色資訊區整塊皆可點擊開啟

## 角色成長與能力值
每名角色具備：
- Level / EXP
- HP / MP
- ATK / MAG / DEF / RES / AGI
- CRIT / EVA
- Move / Jump / Range
- 經驗值會由造成傷害、擊倒敵人、治療、反擊與使用道具取得
- 升級會成長 HP、MP、攻擊、魔力、防禦、魔防與速度，並回復 HP / MP
- 點擊右側角色立繪可開啟完整能力頁

## 技能
### 哈羅 Halo｜遊俠
- 迅射：低 MP、穩定遠距攻擊
- 盲點狙擊：長射程、高倍率、高爆擊
- 瞬步射擊：攻擊後獲得「疾風」，提升速度與迴避

### 波波 Bobo｜法師
- 火球：單體魔法
- 爆炎風刃：十字範圍魔法
- 風縛：魔法傷害並附加緩速

### 泡泡｜舞孃
- 鼓舞之鈴：範圍治療
- 輕靈之風：範圍增加 Move、速度與迴避
- 安眠舞：範圍沉睡控制

## 道具與狀態
- 高級藥水：回復 HP
- 魔力露：回復 MP
- 淨化草：解除負面狀態
- 已實作輕靈、疾風、緩速、沉睡等狀態效果與持續回合

## 存檔
- 我方可操作、且沒有暫定移動時可按「儲存戰鬥」
- 每個新我方回合也會自動存檔
- 標題畫面會顯示「讀取存檔」

## 美術與音訊
- 使用者提供的三張正式角色設定圖保存在 `assets/reference/user-art/`
- `assets/user-character-art/portraits/`：哈羅、波波、泡泡正式立繪，已接入角色面板與能力頁
- `assets/generated/sprite-atlas/halo_4dir.png`、`bobo_4dir.png`、`pao_4dir.png`：四面向待機 Atlas；每張 1254×1254，2×2 等分，排列為左上正面、右上右側、左下背面、右下左側
- `assets/generated/animations/`：三位主角正式 4方向×6幀動畫；每人包含 `walk`、`attack`、`skill` 三張 1448×1086 Sprite Sheet
- 移動時播放 Walk；普通攻擊與反擊播放 Attack；技能播放 Skill，動畫結束後回待機
- 敵軍暫時沿用 Canvas／舊美術，三位主角優先使用新版正式人物
- 原始 SVG 立繪仍保留在 `assets/portraits/` 作為備援
- 背景音樂與戰鬥音效以 Web Audio 即時產生，可獨立開關

## 開發檔案
- `index.html`：戰鬥 UI、技能／道具／預測／能力頁
- `style.css`：戰棋 HUD、立繪面板、羊皮紙標題畫面
- `game.js`：地圖、尋路、高低差、回合、AI、技能、道具、EXP、狀態、動畫、音訊、存檔
- `ART_ASSET_SPEC.md`：供 GPT 生圖使用的地圖材質、四面向角色、動畫、技能 VFX、立繪與檔名／尺寸規格
- `smoke-test.js`：透過瀏覽器 DevTools Protocol 驗證啟動、移動、撤回、技能選單、能力頁、範圍顯示、角色自動切換與存檔
